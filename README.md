# Okra1 – Ratų servisas

Profesionalus ratų serviso svetainė, sukurta Vilniaus verslui.

## Techninės technologijos

- **Vite** – Greitas build įrankis
- **TypeScript** – Tipų saugumas
- **React** – UI framework'as
- **shadcn-ui** – Komponentų biblioteka
- **Tailwind CSS** – CSS framework'as

## Kaip paleisti projektą

Turite turėti įdiegtą Node.js & npm – [diegimas su nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

```sh
# 1. Klonuokite repozitoriją
git clone <YOUR_GIT_URL>

# 2. Eikite į projekto katalogą
cd wheel-tire-experts

# 3. Įdiekite reikalingas priklausomybes
npm i

# 4. Paleiskite development serverį
npm run dev
```

## Papildomos komandos

- `npm run build` – Sukurti production build
- `npm run preview` – Peržiūrėti production build
- `npm run lint` – Paleisti ESLint
- `npm run test` – Paleisti testus
